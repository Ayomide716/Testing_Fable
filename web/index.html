Zero-knowledge clipboard

Copy on your computer.
Paste on your phone.

ClipSync pairs a desktop agent with your phone over a single QR scan. Everything that crosses the network is sealed with AES-256-GCM under a key that never leaves the two devices — the server stores ciphertext and nothing else.

Each payload is base64(nonce ‖ ciphertext ‖ tag). The room id is the authenticated associated data, so a payload lifted into another room fails its tag check before any plaintext exists.

03

How pairing works

Four steps, in this order — each one depends on the last.

  1. 01

    The desktop makes the key

    32 bytes from the OS random source, plus a single-use join code. Only the SHA-256 digest of that code is ever sent to the server.

  2. 02

    The QR carries it across

    The key travels from your screen to your camera and nowhere else. It is not uploaded, escrowed, or derived from a password.

  3. 03

    Both screens show the same checksum

    A short fingerprint derived through SHA-256. If the two don't match, stop — something else produced that code.

  4. 04

    Copy, then tap to paste

    Text copied on your computer arrives as ciphertext. Your phone shows "New copied text received. Tap to copy." — the tap decrypts it and writes to the clipboard, which is the only moment Android and iOS allow it.

04

Run it from source

The agent is a few hundred lines of Python. Reading it takes less time than trusting a binary. 

$ git clone https://github.com/Ayomide716/Testing_Fable.git
$ cd Testing_Fable/desktop
$ pip install -r requirements.txt

$ export SUPABASE_URL="https://<project>.supabase.co"
$ export SUPABASE_ANON_KEY="<anon key>"

$ python -m clipsync pair    # shows the QR
$ python -m clipsync run     # starts syncing

On an Intel Mac, this is the only route — the packaged macOS build is Apple silicon only. Downloaded a packaged build instead? Every release ships a SHA256SUMS.txt; check it with shasum -a 256 -c SHA256SUMS.txt on macOS or Linux, or Get-FileHash on Windows.

!

The packaged builds are not code-signed.

macOS Gatekeeper and Windows SmartScreen will both warn on first launch. On macOS, right-click the binary and choose Open, or run xattr -d com.apple.quarantine clipsync. Signing needs a paid Apple Developer ID and a Windows certificate — until those exist, verify the checksum instead, or run from source.
